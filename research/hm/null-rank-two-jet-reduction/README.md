# Collected rank-two jet identity

Portable formal proof-and-audit packet. RESULT.md is the proposed bounded collection; REVIEW.md accepts it under explicit rational, determinant/derivative and transport premises. The public-ready packet is local only and has not been published.

Run with Python 3, standard library only:

    python check.py
    python -O check.py
    python verify_bundle.py

No network, production source imports, physical input files, matrix instantiation, or actual matrix-polynomial products are used. The checker proves coefficientwise universal scalar identities. Dependencies are frozen exact supplied source records or declared excerpts; PROVENANCE.json identifies their hashes and limits. Full-sign and quartic results are prior work. This packet changes only the representation of R_alg inside the complete remaining-target normal form.
