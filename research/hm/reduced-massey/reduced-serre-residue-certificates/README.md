# Derive reduced Serre residue certificates

The exact normalized residue applied to the reduced representative, its witness criterion, finite-support/cutoff boundary, and finite-sum realization of all four upper and eight lower parameter functionals.

## Reused context

The universal trace normalization and general Serre-pairing argument already appear in the ordinary-cubic residue context. They are retained, with the reduced representative and its specific hypotheses, rather than counted again. The reduced detection and parameter-functional interface are additional.
