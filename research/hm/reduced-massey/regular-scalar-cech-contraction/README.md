# Construct regular scalar Čech primitives

A signed finite Laurent-monomial deformation retraction at scalar twists 0, −1, −2; regular boundary corrections; and the exact abstract Čech–Dolbeault comparison boundary.

## Reused context

The smooth reduced formula is context from the orbit-Cartan theorem, not reconstructed here. Scalar homotopy does not make smooth representatives algebraic and does not supply a multiplicative inverse to analytification.
