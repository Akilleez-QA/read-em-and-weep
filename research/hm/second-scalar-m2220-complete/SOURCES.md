# Public dependencies and evidence boundaries

## Standalone finite arithmetic

The replay requires only the seven files in this directory and the Python standard library. It has no runtime dependency on another pull request. Its unconditional arithmetic conclusion is: the eighteen supplied exact quotients, under the explicitly derived selector for L_minus and m=(2,2,2,0), have signed sum zero.

The geometric interpretation is conditional on the pinned reduced model, the correct L_minus source construction and the source-to-residue comparison hypotheses. This package does not turn the original scalar's source certificates into certificates for a different map.

## What remains external for the new map

1. The complete L_minus source construction from the pinned geometric model and declared residual: full contraction side conditions and frames, unchanged carrier-tail and left prefactor, plus the new column-5 right prefactor.
2. Fresh numerator support enclosures 47/215/454 for all axes, legal-line comparison, all-entry pole bounds, and safe reversed homogeneous extraction in the `(9,44,23)` window. The old factor-48 diagnostic and old scalar-specific bounds cannot discharge these gates.
3. New-map normalized leading sources, ordered-pair circuits, exact integer clearing, and full source-node evaluation producing the eighteen quotients.
4. Reproducible terminal reconstruction from publicly distributed checkpoint data. Historical independent audits verified terminal products in exact integer and Fraction arithmetic but did not reevaluate source DAG nodes; this package contains their hash anchors, not their full archives.
5. The mathematical source-to-obstruction attribution needed to interpret this finite result in the ambient geometric problem. Vanishing of one selected scalar coordinate does not supply injectivity, full scalar-map vanishing or full-obstruction vanishing.

No verified public package completing this entire new-map regeneration chain is asserted here. This is an explicit remaining reproducibility/source-attribution boundary, despite the complete finite all-eighteen supplied-data contraction.
