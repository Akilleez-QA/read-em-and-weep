# Independent audit: constant-rank kernel nets

Verdict: PASS for Sections 1–7, with no required corrections.

## Classification

The P² universal constant-rank map has line kernel and cokernel. Its K-theory/Chern-character equations correctly force O(−1) and O(2). The kernel inclusion supplies three linear forms with no common projective zero, hence an isomorphism from the three-dimensional parameter space K to W. This justifies using the same x both as parameter and as the kernel vector, preserving the endomorphism trace condition.

For each row the identity r(x)x=0 forces its coefficient matrix to be skew-symmetric, and the linear syzygy space is exactly the constant span of the rows of the universal cross-product matrix. Therefore M(x)=B C(x) is justified without assumptions about higher syzygies. If B has rank two, choosing nonzero x perpendicular to its kernel vector puts that kernel vector into im C(x), forcing rank M(x)≤1; ranks zero or one for B are likewise impossible. This verifies invertibility, including isotropic x.

Trace orthogonality against all skew-symmetric matrices forces B symmetric. The factorization B=P P^T over C then produces P^{-1}KP=P^T(skew)P, which is exactly the full skew-symmetric space. This is genuinely conjugacy, not merely arbitrary left-right matrix equivalence.

## Quadratic and frame geometry

The cross-product square identity gives q(C(x))=−2(x_1²+x_2²+x_3²), so the restricted trace-square quadratic has rank three. Since the determinant polynomial vanishes identically, the fixed-K incidence has exactly the reduced conic-complement scheme structure claimed.

After determinant-line trivialization, the orientation parameter remains a functional on the tautological line. The explicit normalization N=A/lambda(A) is invariant under changing that line generator and correctly identifies the orientation cover with q(N)=2. The inverse functional specified by lambda(N)=1 is regular. The affine quadric is smooth, and irreducibility follows from the impossibility of factoring a rank-three quadratic-plus-constant into affine linear factors.

The imported eigenline construction therefore gives a nonempty smooth irreducible five-dimensional fixed-W zero-frame scheme. Irreducibility of the torus bundle follows from local triviality over the irreducible quadric; distinct nonempty trivializing opens intersect. No global trivialization or smoothness of an unknown varying base is inferred.

## Four-dimensional-kernel corollary

Section 7 is valid. The P³ constant-rank obstruction first guarantees h is nonzero. If q has rank at least three, the earlier factor criterion supplies existence. If q has rank one or two and spectral incidence were empty, that criterion forces h to have a linear factor. The corresponding three-dimensional hyperplane is determinant-zero and rank-one-free, so the newly proved classification forces its restricted q to have rank three. This contradicts the monotonicity of quadratic rank under restriction. The q-identically-zero case is correctly excluded from this corollary rather than silently resolved.
