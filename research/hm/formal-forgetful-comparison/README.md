# Comparing parity and unrestricted formal continuations

The full formal forgetful map is injective, but not surjective on the inversion-equivariant abelian fourfold, for the fixed-literal-base marking specified in the proof.

This sharpens the one-step comparison in PR425:

- An unrestricted marked formal equivalence between two reversal-compatible objects can be replaced by a reversal-compatible formal equivalence.
- An unrestricted formal class admits a reversal-compatible representative exactly when every finite truncation admits one. No purely infinite-order obstruction remains after the finite tests, but no uniform test-order bound is proved.
- Nonzero complementary one-step classes continue to unrestricted formal objects outside the parity image, using the retained unrestricted literal lifting input.

The proof explicitly removes unrestricted lower automorphisms by chart 2-units before applying the one-step comparison. It does not simply extrapolate one-step injectivity to the limit.

Exact dependencies are [PR436](https://github.com/Akilleez-QA/read-em-and-weep/pull/436) at `502c978a17cd7037d740d4d08d373c1cb8bd5829`, [PR425](https://github.com/Akilleez-QA/read-em-and-weep/pull/425) at `df433cdd359fa9c7750bf9c8b9765229eac534f6`, [PR416](https://github.com/Akilleez-QA/read-em-and-weep/pull/416) at `c71356722bc7bd1a426d26ea0ca6d050f4c3ed81`, and the [unrestricted literal lifting proof](https://github.com/Akilleez-QA/read-em-and-weep/pull/1#issuecomment-6259748725).

All-order means coefficientwise formal ambient continuation with adjustable products. The result is about marked object-class sets, not full faithfulness of the unitary 2-groupoid, representability, unrestricted automatic normalization, modules, periods, convergence, algebraization, or algebraic cycles. Initial-marking changes and geometric/discrete automorphisms remain outside the theorem. No selected source or model is evaluated.
