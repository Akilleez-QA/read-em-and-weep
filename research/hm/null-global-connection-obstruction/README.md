# Record the global connection obstruction

The four-term K-class gives Δ(F)=60 theta² and its nonzero pairing 1440. Under the inherited bundle identification, F and all line twists admit neither global holomorphic connections nor smooth projectively flat connections; the projective frame bundle admits no holomorphic connection. The exclusions persist on finite étale covers.
