# Exclude trace-metric CM lifts in rank two

Conditional projective CM nonisomorphism excludes global regular similarities between the tracefree adjoint bundles, including trace isometries and the stated line-valued conformal variants. Both the intrinsic null-conic and oriented Lie-algebra proofs are retained.
