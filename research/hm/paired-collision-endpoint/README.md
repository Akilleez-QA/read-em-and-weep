# Exact order-six paired-character endpoint

The [full proof](PROOF.md), conditional on the exact full paired-character
filtration, proves
\[
 H^2(I_D^6E)_\chi^\vee=Q\oplus Q,\qquad
 Q=\frac{H^1(B_0(6))}
 {t_2H^1(B_0(4))+t_3H^1(B_0(3))}.
\]
Both copies come from the actual adjacent syzygy maps, with incoming
multiplication images retained. The third coefficient group is zero.
The existing endpoint upper bound gives \(2\dim Q\leq60\).

Thus lowering the whole-coefficient vanishing from order seven to six
is equivalent to one explicit multiplication-surjectivity question.
Its answer is not evaluated. A nonzero ideal-cohomology group would
not by itself prove a nonzero image in unrestricted cohomology or
a nonzero source obstruction.
