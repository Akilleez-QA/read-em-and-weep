The holomorphic-connection obstruction is valid without assuming the connection is flat: its curvature has type (2,0), whereas the same characteristic class has Hodge type (j,j); compact Kähler Hodge decomposition forces each positive-degree Chern character to vanish. A projective holomorphic connection induces an adjoint holomorphic connection, so its exclusion requires no lift to GL2. Line twists preserve the adjoint bundle and discriminant. A smooth projectively flat connection likewise induces a flat adjoint connection, so it is excluded by the same nonzero real characteristic class. Ordinary smooth connections are not excluded.
