Read REVIEW.md for the independent result and evidence limits, and PROOF.md for the conditional proof. pins.json lists public immutable source references and exact input hashes. Bundled source files under inputs/ are inert text and must not be imported or executed as part of this review.

The historical determinant receipt claims all 36 exact normalized carrier-pair identities. This bundle verifies its static source/model binding and interpretation, not the truth of a historical execution or a new actual-model computation. The proof's determinant-one and root-line/transport premises remain explicit.

Run `python check.py` and `python -O check.py` for static/formal/invented checks. Run `python test_negative_pins.py` for byte-tampering rejection in isolated copies. Python's standard library suffices. Results are review outputs, not production or physical-evaluation receipts. No external service, network, repository publication, or installed dependency is required.
