# Complete detection of cubic families by the first discriminant neighborhood

## Fixed input and new conclusion

Work over C. Let W be the negative-coordinate binary representation, A=Sym^2 W, D=D5, and T=Sym^8 U tensor Sym^2 W, with U the Galois-conjugate positive binary representation. These are the fixed marked representations of [PR696](https://github.com/Akilleez-QA/read-em-and-weep/pull/696), commit [958244d6d9d3b326f66c073a9d669717c953ec32](https://github.com/Akilleez-QA/read-em-and-weep/commit/958244d6d9d3b326f66c073a9d669717c953ec32). Its [polynomial descent theorem](https://github.com/Akilleez-QA/read-em-and-weep/blob/958244d6d9d3b326f66c073a9d669717c953ec32/research/hm/scalar-parameter-descent/PROOF.md) supplies the intrinsic family rho4 in (T tensor Sym^3(A*) tensor D*)^Gamma. This polynomiality and the target identification are dependencies, not rederived here.

Put X=P(A), parametrizing lines, and let C be the smooth discriminant conic of square quadratics. Let 2C denote its first infinitesimal neighborhood, defined by I_C^2, not a doubled set of sample points. We prove that restriction to 2C detects and reconstructs every cubic family uniquely. The seven-dimensional ambiguity left by square-only restriction in PR696 is exactly recovered by the first normal residual. This is a theorem about possible families, not a computation of the actual rho4.

## 1. The first neighborhood is enough

Write Delta for the discriminant equation, of degree two. The ideal of 2C is generated by Delta^2. Twisting its ideal sequence gives

    0 -> O_X(-1) --Delta^2--> O_X(3) -> O_(2C)(3) -> 0.

Since H0(X,O(-1))=H1(X,O(-1))=0, restriction is an isomorphism

    Sym^3(A*) = H0(X,O(3)) -> H0(2C,O_(2C)(3)).

In particular both spaces have dimension ten. Equivalently a cubic divisible by Delta^2 is zero because Delta^2 has degree four. Surjectivity on global sections, unlike this degree argument alone, also uses H1(O(-1))=0.

The filtration of the doubled conic gives

    0 -> O_C(1) --Delta--> O_(2C)(3) -> O_C(3) -> 0.

Here O_C(k) means the restriction of O_X(k); under C=P(W), it is O_P(W)(2k). The kernel is I_C/I_C^2 tensor O_X(3), hence O_C(1). Its global sections have dimension three, while H0(O_C(3)) has dimension seven. Since H1(O_C(1))=0, the global-section sequence is exact on the right.

These statements are equivariant. Tensoring with T tensor D* and taking Gamma invariants preserves exactness because Gamma is finite and the characteristic is zero. Using the representation counts established in PR696 gives the exact sequence

    0 -> N -> J -> S -> 0,
    dim(N,J,S) = (7,23,16),

where N=(T tensor H0(O_C(1)) tensor D*)^Gamma, J=(T tensor H0(O_(2C)(3)) tensor D*)^Gamma, and S=(T tensor H0(O_C(3)) tensor D*)^Gamma. Restriction identifies J with the entire possible family space. The new jet datum recovers all seven channels omitted by restriction to C, with none left invisible.

## 2. An invariant, explicit global splitting

Use coordinates (x,y,z) on A for the binary quadratic x s^2+2y st+z t^2. Fix

    Delta=y^2-xz,       Box=partial_y^2-4 partial_x partial_z.

These are invariant under the binary SL2 action; Box is the constant-coefficient contraction associated with the inverse discriminant form, in the stated normalization. Direct differentiation gives Box(Delta)=6. For any linear polynomial L, the product rule and Euler identity give

    Box(Delta L)=6L+4(x partial_x+y partial_y+z partial_z)L=10L.

For a cubic polynomial f, Box f is linear, so define

    L_f=(Box f)/10,       H_f=f-Delta L_f.

Then Box H_f=0. The decomposition f=H_f+Delta L_f is unique: if a harmonic cubic is Delta L, applying Box gives 10L=0. Thus the space Harm_3=ker(Box:Sym^3 A* -> A*) has dimension seven, and restriction Harm_3 -> H0(O_C(3)) is an isomorphism. Indeed all cubics have a harmonic representative with the same restriction, and its uniqueness follows from the preceding calculation.

This provides a fixed SL2-equivariant splitting of the global-section restriction sequence, hence a Gamma-equivariant splitting even after tensoring by T tensor D*. It is not an asserted O_(2C)-module splitting of the sheaf extension. It remains canonical relative to the discriminant geometry: replacing Delta by c Delta and Box by c^(-1) Box leaves the harmonic projector f -> H_f unchanged, while the coordinate L_f scales by c^(-1), as a normal coefficient must.

## 3. Reconstruction from the jet, not from a second derivative test

Given j in H0(O_(2C)(3)), first take its reduced restriction r in H0(O_C(3)). There is a unique harmonic cubic H with H|C=r. Subtract H|_(2C) from j. The difference lies in the kernel O_C(1) of the first-neighborhood sequence, so it has a unique normal residual ell in H0(O_C(1)), with

    j-H|_(2C) = Delta ell.

There is a unique linear polynomial L on A restricting to ell, since H0(O_X(1)) -> H0(O_C(1)) is an isomorphism. Now f=H+Delta L is the unique cubic giving j. All operations are linear and equivariant, and apply coefficientwise to the h-linear T-valued family.

In particular, if the reduced restriction is zero, H=0 and the intrinsic first normal class corresponds to L|C under the identification using Delta. Thus

    f|C=0 and its first normal class=0  <=>  f|_(2C)=0  <=>  f=0.

For nonzero reduced restriction there is no unqualified intrinsic normal component without a splitting. The harmonic subtraction above specifies one; an arbitrary transverse derivative also contains the derivative of H. Box itself is a SECOND-order formal parameter operator, not a first transverse derivative. Its formula describes the same global harmonic decomposition after reconstruction; the geometric sufficiency of first normal data follows from the double-conic sequence, not from misidentifying Box with a first derivative.

Applied conditionally to rho4, this gives an exact 16-plus-7 normalized description and a complete vanishing criterion. It identifies what additional universal data would settle the square-invisible ambiguity. It does not supply those data or evaluate any selected source direction.
