# Reproduce the shared-D gluing checks

Run with ordinary Python 3 from this directory:

    python verify.py
    python -O verify.py

The checker uses only the standard library and characters.py, the fixed physical-W McKay recurrence. It pins the four immutable source commit/path/blob/SHA256/UTF8-length tuples, verifies the complete retained source texts, and checks the displayed universal representation, cohomology, degree and extension arithmetic. All checks remain active with -O. No raw connector response is required.

The geometric proof in PROOF.md, especially the evaluation diagrams, exact image assertions, divisor argument and actual scalar cancellation, still requires independent mathematical review. The checker does not select any actual curve, coefficient, parameter, point, jet, tensor, matrix or instance rank, and does not search bundle candidates.

INPUTS.json and the complete inputs/ texts provide offline source evidence. Independent freshness and whole-proof review are recorded separately in compact review metadata. Duplicate raw connector responses remain local audit material and are excluded from publication. The proof does not exclude either of its two degree-eighteen jet-kernel alternatives or claim a rank/image for its final induced map.
