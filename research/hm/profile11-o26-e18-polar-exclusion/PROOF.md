# The basepoint-free O(26) branch cannot have source E18

## Result and scope

For the zero-original-defect maximal profile-(1,1) label

    G3.11.8ae96830fd21,
    A_q=2 O(-8)+O(26), B_q=O(-28)+2 O(6),

the source

    E18=2D O(-2)+Wp O(-3)+V O(-4)+2 O(-8)

is impossible. The argument classifies a small exact kernel, then uses its actual internal derivative image and the first polar of the embedded top block. It does not declare an abstract summand horizontal or assume that E^+ has no constant sections.

This is a source-branch exclusion, not an exclusion of the full label. Together with the pinned divisor reduction and E0/E10 result below, the only source left for this label is E10, with a basepoint-free degree-twenty-eight top system and the constant fifteen-space described there. Source2 and the global rank problem remain open.

Only universal equivariant character identities and vector-bundle exact sequences are used. There are no selected actual HM/source coefficients, parameters, points, derivative values, matrices, source-instance ranks, selected models, scans, or large computations. The bounded verifier checks the small displayed support classification and Hom identities, not an all-twist numerical envelope.

## 2. Actual kernel and first-polar image

Assume E has source E18, and let

    F=2D O(-2)

be its canonical top block. It is saturated in E and therefore in H O. The quotient E->A_q restricts to p:F->O(26), since maps to 2 O(-8) vanish by degree. The strict-top vanishing injects the coefficient 2D into H0(O(28)). PR813 excludes a common divisor of degree12, while degree20 would leave only Sym8 W=P+D and cannot contain 2D. Thus p is everywhere onto. Put

    K0=ker p,
    0 -> K0(2) -> 2D O -> O(28) -> 0.                 (1)

In particular K0 has rank9, degree-46 and all splitting degrees at most-3. The exact cohomology gives

    H1(K0(2))=A+V+2P+D,
    chi_G(K0(3))=-W-Wp-T.                             (2)

Original defect zero makes the actual derivative image A_q saturated in Q(-2), Q=(H O)/E. Its positive line O(26) is saturated there as well.

The actual internal derivative of K0 is the O-linear map

    kappa:K0 -> (E/F)(-2)=Wp O(-5)+V O(-6)+2 O(-10).

Write J=im kappa as an image sheaf. Let B be the raw sheaf generated by F and its first derivatives, before saturation, and I its derivative image. Then

    0 -> J -> I -> O(26) -> 0,
    0 -> F -> B -> I(2) -> 0.                         (3)

These are exact sequences of locally free sheaves, though B need not yet be saturated in H O. They use the actual original connection and quotient maps, not an arbitrary bundle extension.

Euler's identity for quadratic columns identifies B with the image of the first-polar map

    2D tensor W tensor O(-1) -> H O.

Consequently B(1) is globally generated; and B injects in a constant bundle. Every splitting degree of B is therefore 0 or-1. If t=length(F^+/B), invariance implies t=0 or t>=12. Also

    0 <= t <= -deg B.                                (4)

In particular deg B>0 is impossible, and -12<deg B<=0 forces B=F^+. When B is saturated, its degree-zero part C O is an actual constant subbundle. The quotient B/C O is saturated in (H/C) O and has only degree-1 summands.

## 5. Elementary polar facts used for the remaining rows

Suppose B=C O+L O(-1) is saturated, and let bar F be the image of F in (H/C) O. Then bar F is contained in L O(-1), and its derivatives also lie there: this is the constant projection of the defining first-span property of B. A nonzero equivariant projection containing a whole direct linear block U O(-1) is therefore impossible. Indeed the first span of an embedded linear bundle U O(-1) is its nonzero constant coefficient span. It would lie in L O(-1), contradicting H0(L O(-1))=0. This reasoning uses an actual constant ambient quotient; no assertion about an abstract splitting alone is being made.

For 2D O(-2) mapping to S O(-1)+T O(-1), the D-to-S map is quartic contraction, everywhere onto S O(-1), and the D-to-T map is multiplication, everywhere injective. Their multiplicity-space rows will be denoted lambda and nu. If these rows are independent, a constant change of the two D factors makes their images contain the entire S O(-1), giving the preceding contradiction. If dependent and nu is nonzero, the projection has kernel exactly one constant-multiplicity D O(-2).

A second elementary fact is that no D O(-2) can embed equivariantly in the constant space (A+D) O. Every such quadratic coefficient map factors through D tensor Sym2 W. Its restriction to the tautological O(-6), whose fiber is the sixth pure power, factors through Sym6 W=V+P. There are no maps from V+P to A+D, so every such map kills this nowhere-zero line. This contradicts injectivity.

## 6. Exclude the six remaining rows

### 6.1. J=O(-10)

Here B=C O is constant, with C=A+P+D, rank12. Since F is saturated, X=C O/F is a globally generated rank-two bundle of degree20. Sequence (3) requires an everywhere-surjective equivariant map

    X -> O(28),      ker=O(-8).                       (8)

The central parity and rank rule out an odd two-dimensional coefficient: that would have equal splitting degrees10 but require odd degree. Thus

    X=O(a)+O(20-a),   a even, 0<=a<=10.

For a=0,2,4,6,8,10, the two invariant degrees of a map to O(28) are respectively

    (28,8), (26,10), (24,12), (22,14), (20,16), (18,18).

The first, second, fourth and sixth pairs have no nonzero invariant channel. For (24,12) both entries are divisible by f12. For (20,16) only the f20 entry can be nonzero. None can be onto everywhere. This contradicts (8).

### 6.2. J=Wp O(-5)+O(-10)

Now B=(A+D) O+T O(-1). The projection of F=2D O(-2) to T O(-1) is a single multiplicity row. It is nonzero, since otherwise rank10 F would lie in the constant rank8 part. Its kernel is a D O(-2), which would embed in (A+D) O. Section5's tautological-line obstruction rules this out.

### 6.3. J=O(-10)+O(-12), or J=W O(-11)

Both give B=A O+(S+T) O(-1). The two polar rows lambda,nu must be independent: if dependent, their common kernel contains a D O(-2) of rank5 inside the constant A of rank3. Independence, however, makes the projected F contain S O(-1), contrary to Section5. Thus neither row is possible.

### 6.4. J=V O(-6)

Here B=(A+V+P) O+S O(-1), with constant rank10. The projection F->S O(-1) cannot vanish: if it did, the saturated F and the constant ten-space would be equal as saturated subsheaves of H O, contrary to degree F=-20. A nonzero multiplicity row is onto S O(-1). Its linear first span gives the contradiction of Section5.

### 6.5. J=Wp O(-5)+V O(-6)

Here

    B=(A+V) O+(S+T) O(-1), C=A+V, dim C=6.

Independent polar rows are impossible by Section5. If nu=0 and lambda is nonzero, the projected image is all S O(-1), also impossible; if both vanish, rank10 F would lie in C of rank6. Thus the rows are dependent and nu is nonzero. The exact sheaf intersection is

    F intersect C O=D O(-2).

It is saturated in C O, because F is saturated in H O. Consequently C O/(F intersect C O)=O(10) injects in X=B/F. The map X->O(28) in (3) kills this O(10), because H0(O(18)) has no invariant. It therefore injects into the kernel

    J(2)=Wp O(-3)+V O(-4),

which admits no nonzero map from O(10). This final contradiction excludes the row.

All possibilities (7) have been excluded, proving that E18 is impossible. The cumulative source reduction in the opening statement now follows from PR813 and PR817, without any claim that the remaining E10 source or full label has been excluded.
