# Exclusion of the ordered maximal rank-four plateau (3,1)

## Theorem and exact scope

Retain the actual geometric, equivariant primary-module, necessity and transfer premises in the six complete original sources carried by the pinned proof packets below. Then the actual generic second fundamental form cannot have rank four with maximal ordered plateau (k,l)=(3,1).

This is a conditional exclusion of one ordered rank-four profile. It does not prove generic SF rank at least five, square-map surjectivity, full-adjoint invertibility, the original proof repair, or any improvement of the distinct cone specialization. No actual coefficients, parameter values, jets, matrices, actual-instance ranks, or historical source enumeration are evaluated.

The proof exhausts the possible generic ranks 1,2,3,4 of one and the same nonzero restricted dual cubic derivative. It neither swaps the unequal actual bundles nor assumes a canonical or unique cubic section copy. Positive determinant and inverse-image torsion defects are retained until the applicable branch itself forces their vanishing or supplies a contradiction.

## 2. Assume the ordered profile and fix a section copy once

Assume for contradiction that the generic SF rank is four and the maximal ordered plateau is (3,1). Its saturated stages are

    F0 < F1 < F2 < F3=E < F4,
    ranks 5,9,13,17,21.

Write Li=Fi/F(i-1), each of rank four, and B=L3=E/F2. The genuine regular derivative maps Li -> L(i+1)(-2) have torsion determinant defects delta_i in the invariant semigroup <12,20,30>.

The actual Euler presentation gives

    chi_G(Q*(3))=T6-2W-S4.

Since H1(Q*(3)) is a genuine representation, H0(Q*(3)) contains at least one T6 copy. Choose one equivariant inclusion

    i:T6 -> H0(Q*(3))

and keep this same choice throughout. No canonical splitting, uniqueness, or injectivity of the associated evaluation bundle is assumed. Compose evaluation with the actual dual derivative:

    psi_i:T6 O -> Q*(3) -> E*(1),
    J_i=im psi_i.

The full dual derivative has generic rank four, the same as the original second fundamental form by its negative-transpose identity. Hence rank J_i<=4. Arbitrary-rank endpoint persistence for the reversed four-block plateau gives H0(F4^perp(3))=0. Since F4^perp is the actual derivative kernel of Q*, the derivative on H0(Q*(3)) has zero kernel. In particular psi_i is nonzero. Its actual image is locally free on the smooth curve, and its generic rank r is therefore in {1,2,3,4}.

All four branch theorems quantify over an arbitrary chosen T6 copy. The same i satisfies every branch hypothesis; no theorem changes i, selects a different derivative, or compares incompatible source choices.

## 3. Exhaust the image rank

### r=4

The cubic-image theorem (1) excludes rank four. It derives the complete source-compatible image shapes using all four necessary E sources, not only source Z. Its saturation and Euler/Hom arguments preserve positive defects until their local subcase forces a restriction. Thus the full-rank branch is impossible.

### r=2 or r=3

The lower-image classification (2) gives exactly thirteen necessary image/quotient pairs, with the actual kernel in

    0 -> N -> B -> J_i*(1) -> 0.

It does not identify a lower-rank image with the full rank-four annihilator. The invariant Ext calculations prove the bundle splitting where used, including the two ordinary nonzero-Ext cases; no horizontal splitting or splitting of the later inverse-image extensions is presumed.

The complete degree ledger forces delta3=0 for these thirteen pairs. Put Z=F4^perp. Then the actual last derivative map gives L4=B(2), and there is an exact sequence

    0 -> Z -> Q* -> B*(-2) -> 0,
    maxdeg Z<=-4.

The actual derivative of Z takes values in B*(-4). Its twist-four section map is injective: a kernel section lies in a degree-zero top summand of Z(4), defines a saturated negative-degree subbundle of the constant ambient, and has no derivative component in (Z/K)(-2); it would therefore be horizontal, contradicting its negative degree. Consequently

    chi_G(Z(4)) <= H0(Z(4)) <= H0(B*).

Exact additivity gives chi_G(Z(4))=chi_G(Q*(4))-chi_G(B*(2)). The uniform lower-image exclusion (3) verifies

    [V:chi_G(Q*(4))-chi_G(B*(2))-H0(B*)]=1

for each of the thirteen actual quotient shapes. This is a genuine representation contradiction, not a dimension test. It excludes all 96 torsion partitions, including 83 positive-defect partitions, without assuming delta1=delta2=0. Thus neither r=2 nor r=3 is possible.

### r=1

The cubic-image theorem (1) forces J_i=O(9), and only the necessary source D can support it. This does not retrospectively impose source D in the other branches. The target maxdeg E*(1)<=9 proves J_i is saturated, so the true quotient sequence is

    0 -> N -> B -> O(-8) -> 0,
    rank N=3.

The complete actual determinant ledger gives c3=deg B in {-2,0,2,4,6,8,10}, so deg N=c3+8 is between 6 and 18. Since N(2) embeds in Q and the rank-independent dual-type theorem gives maxdeg Q<=8, every ordinary degree of N is at most 6, and consequently at least -6. Thus H1(N(8))=0, proving B=N+O(-8) even as an ordinary bundle and equivariantly; this is not an assumed extension splitting.

The rank-one theorem (4) derives exactly 53 abstract N shapes by two complete finite enumerations. The valid two-step section inequality and common-Q-target necessary injection tests leave exactly sixteen. Seven have c3=-2 or0. Their actual lower two determinant defects vanish, allowing exact associated-graded Euler additivity; none of the complete 13- or 46-element endpoint domains satisfies both required Euler identities. The possible delta3=12 when c3=-2 is retained until this contradiction.

The nine remaining shapes have c3>0, which forces delta3=0 in the complete ledger. The same actual upper-endpoint section argument then applies, and each has physical V excess exactly one. These are excluded without setting the lower two defects to zero. Hence r=1 is also impossible.

## 4. Conclusion, verification and limits

The nonzero image rank r must belong to {1,2,3,4}, and every member of that set has been excluded for the same fixed section copy and the same ordered actual plateau. The assumed rank-four profile (3,1) therefore cannot occur, conditional on the retained original premises.
