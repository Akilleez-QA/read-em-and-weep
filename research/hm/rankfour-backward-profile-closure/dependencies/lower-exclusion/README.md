# All lower dual-cubic images are excluded

Conditional on the retained actual geometry, a restricted dual cubic derivative in ordered maximal rank-four (3,1) cannot have image rank two or three. A uniform physical-V obstruction excludes all 13 previously necessary quotient pairs and all 96 torsion partitions, including 83 with positive defects.

The key actual endpoint injection is H0(F4^perp(4)) -> H0(B*). Every candidate violates its Euler-character consequence by one physical V. No H1 vanishing, globally zero defects, or horizontal splitting of an inverse-image extension is assumed.

The full frozen earlier packets are included at lower-image/ and cubic-image/. Together they leave only the rank-one O(9), source-D branch; they do not exclude the whole profile.

Run with the Python standard library from any working directory:

    python3 verify.py
    python3 -O verify.py

Outputs must match RESULT.json. PROOF.md contains the geometry; OBSTRUCTIONS.json records all thirteen exact characters. Original source authentication and both earlier certificates are rerun. No actual instance or historical candidate enumeration is evaluated.
