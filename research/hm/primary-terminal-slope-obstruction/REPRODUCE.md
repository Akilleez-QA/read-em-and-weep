# Reproduction

Run python verify.py and python -O verify.py. Both outputs must agree with RESULT.json. Only Python standard-library arithmetic is required.

The checks authenticate six full immutable originals; verify the fixed nine-class primary and cohomology representation identities; obtain the four candidate types by the four unit vectors solving a total-slack-one equation; check their rank, degree, and terminal/Euler characters; and verify elementary P1 cohomology controls and the failure of the three specified old E types. No HM/source coefficient, tensor, matrix, point, parameter, derivative, jet, actual-instance rank or search is evaluated.

The actual canonical slope-subspace theorem and its functorial cohomology proof require the written argument and independent whole-proof review. The checker does not prove geometric coverage of a rank-three frontier merely by inspecting an existing list. No full-goal result is claimed.
