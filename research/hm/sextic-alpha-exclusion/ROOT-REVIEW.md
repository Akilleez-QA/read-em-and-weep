# Root mathematical check

The vanishing lemma uses the actual normalizer representation of H0(E), not only its dimension. Its irreducibility and nonzero evaluation on the invariant reduced curve C force H0(I_C E)=0. The primary source identification with the even four-dimensional character is independently checked.

In the generic alpha or line case, the common section kernel is exactly one-dimensional, so it spreads to a rational map from the four-dimensional hyperplane parameter space into P3. A positive-dimensional fiber fixes a section. Its degree-ten pure section-zero scheme has a surface component containing the varying integral sextics; proper hyperplane intersection forces degree at least six. The degree bound forces Heisenberg invariance. If no line of C lay in that surface, all twenty-five section-point maps would be constant on the irreducible fiber, contradicting their spanning hyperplanes. Thus the section vanishes on all C, contradicting the lemma.

The proof excludes generic alpha and line families, not isolated special hyperplanes. The beta-plane case remains open. This is authored and independently mathematically reviewed, not formally verified, and uses no selected actual evaluation.
