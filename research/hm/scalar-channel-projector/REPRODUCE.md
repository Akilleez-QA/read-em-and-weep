# Bounded reproduction

Run python verify.py and python -O verify.py. Both outputs must be
byte-identical with RESULT.json. The checker uses only the standard
library, explicit failure exceptions, fixed nine-class characters,
and rational arithmetic in the universal algebra k^2=k/4.

The five original source copies are authenticated by exact immutable
commit URLs, Git blob hashes, SHA256 and byte lengths in INPUTS.json.
Refresh original authentication through those exact URLs and compare
raw UTF-8 contents. Hashes authenticate bytes, not geometric correctness.

No actual HM/source arrow, coefficient, parameter, point, derivative,
jet, matrix, instance rank or scan is constructed or evaluated.
The universal pair arithmetic is not an actual multiplicity matrix.
It only checks the consequences of the written trace identity.

The decisive proof steps requiring mathematical review are the
R-linear primary inclusion, the exact primary locations of H and
Q^-1 B0, invertibility of the unknown actual Q_X, the coevaluation
scalar projection, and normalized rectangular trace cyclicity.
These belong to PROOF.md and REVIEW.md, not to a numerical certificate.
