# Portable rational-divergence reduction

Read PROOF.md for the conditional theorem, exact geometric/rational boundary, certificate interface, source hypotheses, and limits. Run `python check.py` and `python -O check.py`. Python standard library only; no input files, network, production imports, physical/model evaluations or actual matrix-polynomial products. The checker verifies only explicitly invented scalar examples, including a negative mutation. It is not a proof of physical vanishing or an execution admission.
