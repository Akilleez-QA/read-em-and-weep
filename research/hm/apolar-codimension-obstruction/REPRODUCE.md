# Reproduce the universal codimension controls

Requires Python 3 standard library only. From this directory run:

    python verify.py
    python -O verify.py

Both print exactly RESULT.json. Failure checks remain active under optimization. INPUTS.json binds three full public source files by immutable URL, byte length, SHA256 and Git blob SHA1. No network access is needed for replay.

The controls prove formal apolar polynomial identities with an indeterminate parameter, verify balanced-net character identities and degree/rank arithmetic for d=2 through32, test both sharp abstract boundary models, and retain the d=1 failure of the completeness dimension bound. No parameter is sampled and no actual HM/source coefficient, point, jet, matrix, tensor or instance rank is evaluated. The proof establishes the unbounded geometric theorem; these bounded controls are supporting reproducibility, not proof-assistant verification or additional actual-case exclusion.
