## Open boundary and corrections

Root Morita transport is inter-ambient, not an asserted coarse equivalence of two prespecified ambients. Trivial-inertia descent requires a genuine action; weak action coherence needs strictification. Characteristic equality alone is not full ambient comparison, and no mixed value is computed.
