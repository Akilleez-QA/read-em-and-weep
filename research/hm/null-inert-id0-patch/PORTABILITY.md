# Public-bundle adaptation boundary

The original reviewed candidate.patch and both candidate-text files are copied byte-for-byte. The independent REVIEW.md and public-result.txt are unchanged. Original reviewed hashes are listed separately.

The public proof removes private operational-accounting details and describes separate inspection materials without bundling their raw retrieval receipts. Public pin metadata is constructed from whitelisted immutable source URLs/paths, commits, Git blob IDs, lengths, SHA-256 digests, candidate hashes and the mathematical request record. Absolute local paths are replaced with bundle-relative data paths.

The supplied and independent static validators are portable derivatives, not falsely presented as their original reviewed bytes. Both accept a required explicit --source-root argument and read public-pins.json. The independent validator resolves the bundled retained record relative to its bundle root. The supplied validator does not require private retrieval receipts; it reports missing selected dependency edges honestly. Its import scan is limited to the pinned Python source list, avoiding unrelated checkout contents. Their substantive patch/AST checks are otherwise retained.

Normal and optimized validation were rerun with these portable derivatives. The independent validator still checks exact unified-diff reconstruction, original source lengths/SHA-256/Git blobs, retained-record digest, recursive public-scope yield/await exclusion, inert entry signature, certificate identity/poison checks and quotient retention. The supplied validator still checks preserved source construction, exact terminals, old APIs and six rejected mutations. Neither validator imports, compiles for execution or evaluates reviewed source.

The original independent review's findings and limitations apply to the unchanged candidate. The portability edits are documented packaging changes, not a new independent review or expansion of acceptance. No application, publication or physical execution occurred during preparation.
