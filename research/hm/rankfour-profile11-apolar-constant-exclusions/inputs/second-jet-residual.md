## 2. The actual partial coefficient system generates second jets

    ev_2:C O -> P^2(O(10)).                         (9)

## 3. The residual quotient and its actual coherent target

    Q=F*(-2)/ell.                                  (11)

Its length-twelve torsion cokernel and inherited equivariant fiber characters are unchanged. The injection R->Q is not assumed saturated. No connection is placed on R, B0 or Q.

The universal Hom description of the actual line in the first-jet theorem determines Q without choosing any actual coefficients. For F=O(2)+2O(4), the line is a nonzero constant direction in the block 2O(-6) of O(-4)+2O(-6). Thus

    Q=O(-4)+O(-6).                                 (12)

    (a eta,b id):O(-6)->W O(-5)+O(-6),              (13)

    Q=W O(-5).                                    (14)

These are exhaustive zero/nonzero alternatives in a fixed universal Hom space, not choices of parameter values or actual coefficients.

## 4. The forced rank-two character alternatives

The original ambient and hence R have trivial central action. Equivariant Birkhoff splitting, perfectness of G and rank two give only two possibilities: one odd doublet of degree -11, or two negative scalar lines with even degrees. Thus the complete list before characters is

    W(-11),       W'(-11),
    O(-j)+O(-(22-j)),       j=2,4,6,8,10.           (16)

The five scalar partitions are forced solely by negativity, rank two, parity and total degree; this is not a global bundle search. Repeated scalar degrees cannot occur here because the equal degree would be odd.

Fixed-determinant Serre duality gives the following characters. Both doublets in (16) have

    H1(W(-11))=H1(W'(-11))=A_std+V+P+2D.

For the scalar partitions, j=2 and j=8 give

    1+A_std+V+2P+D,

which differs from (15). Each of j=4,6,10 gives exactly (15). Hence only

    W(-11), W'(-11), O(-4)+O(-18),
    O(-6)+O(-16), O(-10)+O(-12)                     (17)

survives the character equality. No existence is inferred from this equality.

## 5. Actual full-rank Hom constraints remove three alternatives per target

## 6. A single extension class gives four necessary S0 splittings

Return to the actual equivariant extension

    0 -> A_std(-8) -> S0 -> R -> 0.                (20)

For finite G in characteristic zero, equivariant Ext1 is the invariant part of ordinary Ext1. This follows by averaging, or exactness of the invariants functor. We compute only the alternatives already forced in (18)-(19).

For R=W'(-11), the ordinary extension group is H1(A_std tensor W' O(3))=0. Thus (20) splits equivariantly and

    S0=A_std(-8)+W'(-11).                          (21)

For R=O(-6)+O(-16), the two equivariant extension groups are

    H1(A_std O(-2))^G=A_std^G=0,
    H1(A_std O(8))^G=0.

Thus

    S0=A_std(-8)+O(-6)+O(-16).                     (22)

For R=O(-4)+O(-18), the O(-18) extension vanishes since H1(A_std O(10))=0. The other group is

    Ext_G^1(O(-4),A_std(-8))
       =(A_std tensor Sym2 W)^G=C,                 (23)

because A_std tensor A_std=1+A_std+D. The zero class yields

    S0=A_std(-8)+O(-4)+O(-18).                     (24)

Every nonzero class is isomorphic after scalar rescaling to the physical cubic evaluation extension

    0 -> A_std(-8) -> S4(-7) -> O(-4) -> 0.        (25)

This extension is nonzero even ordinarily: a splitting would give a nonzero map O(-4)->S4(-7), impossible by degree. Its equivariance is canonical. The one-dimensional invariant Ext space makes (25) the unique nonzero equivariant extension class up to boundary rescaling. Consequently the remaining possibility is

    S0=S4(-7)+O(-18).                              (26)

This proves (7). From (12)-(14) and (18)-(19), form (21) is restricted to the W O(3)+O(4) primal branch with b nonzero in (13). Forms (24) and (26) require the scalar target (12). Form (22) is not excluded by either target.

No splitting in this section is taken to be horizontal. The intrinsic M, its embedding, and the actual constant connection remain the data from Sections 1-2. In particular, identifying an abstract quotient or middle bundle does not assert a block-diagonal derivative.
