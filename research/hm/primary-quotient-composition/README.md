# Canonical primary doublet and complement algebra

The actual primary inclusion has a unique equivariant retraction onto W'O(-3). This canonically splits the actual negative tail into a 6→4→2 summand and a 48→33→18 complementary tail, without a positive-coordinate, Q, Gauss or full-module splitting claim.

Conditionally on the four necessary quotient types, the packet computes both Hom directions, both composition pairings, complement-independent diagonal data, and the exact endomorphism radicals. It does not establish occurrence, geometric coverage or a complete proof repair.
