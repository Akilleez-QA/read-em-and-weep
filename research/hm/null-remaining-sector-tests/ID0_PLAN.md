# Dormant successor for retained detector ID0

This is a static design and review checklist, not an implementation or execution release. The retained thirty-test theorem is [pinned here](https://github.com/Akilleez-QA/read-em-and-weep/blob/f06982d870bdff2ca7b5f48779cd43a94c174d29/research/hm/null-remaining-sector-tests/PROOF.md).

## Exact observable

ID0 is (L_(5,0),Q²), with Q=x1*x2+x3*x4. It requests c[8]+2c[40]+c[72], corresponding respectively to Laurent exponents (-3,-3,-1,-1), (-2,-2,-2,-2), and (-1,-1,-3,-3). These are three terms of one detector. Zero alone is undecided; an authenticated nonzero full pairing would prove nonvanishing under the accepted class comparison.

## Reusable mathematical construction

The pinned [program.py lines101–131](https://github.com/Akilleez-QA/read-em-and-weep/blob/e93cf712f9da4926a8450cc870ed45a7bfc379ab/research/codex-swarm/detector-realization/program.py#L101-L131) assembles the complete scalar L5,0=X13[5,0]+X02[1,3]+X02[4,2] before terminal extraction. This is the same map as the now-redundant ID30. The entire raw-source, original-frame inclusion, J2 lift, signed staircase, and 54/29 outer construction can therefore be reused at the denotation level. Target exponents do not enter that preterminal construction. This does not mean any preterminal value has been computed.

Owner seed30 is a provenance label in the old package. A separate ID0 package needs a source-equivalence lemma for relabeling seed to0 while retaining every other owner field, occurrence distinction, sort parity, weight and cache identity. The old source and refusal paths should remain immutable.

The existing generic scalar compiler already describes this request as three weighted Laurent nodes. The concrete physical route, source-binding manifests, and prospective cost certificate remain request30-specific. Replacing a label is not a valid new certificate.

## Minimal separately held adapter

1. Bind the exact frozen ID0 record, scalar map, frame and ordered terminal weights.
2. Assemble one complete preterminal scalar; select the y-mask15 deck component once. The deck character is distinct from the S4 permutation-sign projection proved to be a boundary and must remain.
3. Call the existing remainder-checked Laurent extraction for each of the three exponent tuples, then combine them as a+2b+c on the same metered exact-arithmetic context.
4. Keep every physical entry point refusing before model or owner construction, until separately reviewed admission.

[The existing Laurent method](https://github.com/Akilleez-QA/read-em-and-weep/blob/e93cf712f9da4926a8450cc870ed45a7bfc379ab/research/codex-swarm/exact-curve-field/field.py#L327-L347) reconstructs the residual denominator and performs exact division on each call. Therefore the smallest adapter has one source sum and three terminal divisions. A shared-quotient API would need its own denotation, meter and lifetime review. Neither design has an established cost advantage yet.

The complete raw representative may be used directly: its class equals the residual30 class. No implementation of the alternating primitive is needed merely to apply the thirty-test theorem, and that primitive must not be presumed to lie in a numerical cutoff.

## Review obligations

- Preserve all seven kinetic terms, three negative gerbe terms before justified cancellation, both Fk and both E terms, physical derivatives, complete ordered faces and original-frame transport.
- Authenticate the exact seed-relabeling/preterminal equivalence and full dependency closure.
- Retain the established common domain and J3 closure premises; a new terminal does not lower source poles.
- Require full rational divisibility before any coefficient lookup. No local-support zero shortcut or coefficient extraction from unassembled rational summands.
- Artificial-only controls should reject altered weights/exponents/indices/maps, missing terms, non-Laurent remainders, poisoned arithmetic contexts and same-size dependency mutations. Refusal tests must not construct physical owners.
- Rebind the prospective cost proof to three terminal divisions and metered accumulation, all retained coefficients and temporaries. The old single-terminal envelope cannot be relabeled. Request counts are not source operation or storage bounds.
- Preserve current guards and require independently established resource and lifetime bounds before any physical computation. Failure, drift or exhaustion is inconclusive, never zero.

No physical polynomial, coefficient, owner traversal, rank calculation or source experiment was executed for this plan. Root checked the actual terminal and meter source text. The remaining value of ID0 is unknown.
