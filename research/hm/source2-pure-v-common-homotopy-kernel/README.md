# Common quadratic homotopy kernel and forced P correction

In the residual-large mechanism, the full-coefficient universal map proves
ker(hT on NC2)=I2. Consequently the residual common kernel has dimension17,
and the common kernel on ker j2 (also on all M2) has dimension21.

Under the additional R=0 hypothesis, that kernel is exactly F2 plus the
12-dimensional first-correction image, and its Q image is F4. The P
correction necessarily has a nonzero separated N0,2 P projection; it
cannot be placed in the residual module. The V/D corrections are residual,
with the D ambiguity retained modulo I2.

Run `python verify.py` and `python -O verify.py` to reproduce RESULT.json.

the actual-map proof. No actual source coefficient or rank is evaluated.
