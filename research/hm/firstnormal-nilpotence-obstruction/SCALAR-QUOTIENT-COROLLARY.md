# A two-dimensional quotient when the abstract scalar is allowed to vary

Fix n,T,A=a²h, with the regular-pair and first-normal hypotheses of the [scalar-slope theorem, PR729](https://github.com/Akilleez-QA/read-em-and-weep/blob/c384ae419983a5031af19c37674df020de1aa5da/research/hm/firstnormal-scalar-slope/PROOF.md). Put B=(S/(f))8, a three-dimensional space, and let δ=[d2] in B. The theorem proves δ≠0. For each scalar s choose any regular weight-four R solving the q² square equation. Existence and h-divisibility are supplied by that theorem; the image K_s=[C/(ah)] in B is independent of R by PR716/724.

The slope law is K_(s+λ)=K_s+aλδ. Therefore the image of K_s in B/kδ is independent of both s and R, and B/kδ has dimension two. This image vanishes if and only if there exists an abstract scalar s with K_s=0. If it exists that scalar is unique: after choosing any s0 and writing K_(s0)=cδ, it equals s0−c/a.

This only eliminates the abstract local scalar parameter. It neither allows the fixed actual scalar to vary nor asserts its value is the cancelling one. The actual immutable class still requires its particular first-normal data. No coefficients, points, derivatives, or ranks of the actual instance are evaluated.
