# Reproduction

Requires Python 3 standard library only. From this directory:

    python verify.py
    python -O verify.py

Both outputs must equal RESULT.json byte for byte. Explicit failure conditions remain active under optimization. INPUTS.json authenticates the full retained public files by byte length, SHA256 and Git blob SHA1. characters.py is byte-identical to its pinned public original. The checks operate on universal characters, integer degree identities and formal monomial pairing identities, never an actual HM instance. PROOF.md contains the geometric argument; these finite controls do not replace it.
