# Rank-two centrality and first-order existence

## Result

For the actual rank-two carrier with holomorphically trivial determinant, the Atiyah square satisfies At(E)²=−15θ² id_E. In the calibrated row/HKR convention, ev_E(π)=−15Π id_E and b=−15Π cancel the full End-valued first obstruction, separately for each specified pair. This is more than a trace identity.

The contribution is the independent curvature/Atiyah proof and sign audit. The explicit formula x=sI−K/2 already appears in the pinned first-order source and is not claimed as a new formula.

Pair-character uniqueness is a separate result, not proved by this note. This note does not prove second-order vanishing, any pure coordinate, or a newly evaluated primitive.
