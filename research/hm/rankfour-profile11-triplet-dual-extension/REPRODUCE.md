# Reproduce the dual-extension checks

Run with Python 3:

    python verify.py
    python -O verify.py

Only the Python standard library is needed. INPUTS.json and the hard-coded pins in verify.py retain the exact complete immutable input bytes, commit/path pairs, SHA256 hashes, and Git blob SHA1 values. characters.py checks the fixed physical-W character recurrence and supplies only the small universal identities displayed in the proof. The explicit checks stay active under optimization.

The checker does not prove the geometric or commutative-algebra arguments by itself. The complete PROOF.md gives the actual extension, the self-contained binary apolar complete-intersection derivation, the connecting-map/polarization identity, the middle splitting, and the actual canonical-subbundle incidence and derivative argument. In particular a small arithmetic replay is not a substitute for whole-proof review.

The degree-twelve invariant is an unnormalized generator of a fixed universal invariant line. No actual HM coefficient, point, parameter, jet, tensor, matrix, instance rank, apolar value, or normalization is selected or evaluated. No bundle-candidate scan or large computation is included. Neither class of the actual extension is selected, the local defect delta remains unresolved, and no fourth-jet or algebraicity conclusion is drawn.

For selected-only replay copy PROOF.md, INPUTS.json, REPRODUCE.md, verify.py, characters.py, and the three files under inputs/ into an otherwise empty directory. Run both commands there. Raw LOCAL* fetch-response duplicates and subsequent exploratory work are not part of the selected publication slice. Compact independent authenticity, whole-proof review, and replay records are provided separately.
