# Cyclic annihilator duality and compressed quintic quotients

## Pinned assumptions

Work over C with S=Sym(T), dim(T)=5, and maximal homogeneous ideal m. Let H be the original graded module generated by W=H_0, dim(W)=2. Its Hilbert function is (2,10,20,20,10,2), supported in degrees 0 through 5. Use the symmetric perfect S-balanced pairing b:H_i x H_(5-i) -> C. Put I=Ann_S(H) and R=S/I, of Hilbert function (1,5,15,25,15,3).

These are the original-module inputs in [PR491](https://github.com/Akilleez-QA/read-em-and-weep/pull/491), commit e9ed26058f69f3b96bdcdf920cb638e9dd68def8, and [PR500](https://github.com/Akilleez-QA/read-em-and-weep/pull/500), commit 86d7e1b5d3aee770ea3e7652c950b29bca1aba10. In particular PR491 identifies Sym^2_S(H) with N=R^vee(-5), using the explicit convention N_d=Hom_C(R_(5-d),C), by

Phi(hh')(q)=b(qh,h').

Fix any nonzero w in W, and a nonzero lambda in W^* with kernel Cw. [PR511](https://github.com/Akilleez-QA/read-em-and-weep/pull/511), commit 55bc80b2cb660edd741c93747df7304ee51a061e, gives, after choosing a generator, H/Sw=A_lambda=S/J_lambda with Hilbert function (1,5,5). The statements below are uniform in w and use no selected source-instance evaluation.

Write D_5(M)_d=Hom_C(M_(5-d),C), with the usual dual S-action. Set L=Sw and K=Ann_S(w).

## 1. The cyclic submodule is a different algebra from the cyclic quotient

The exact sequence 0 -> L -> H -> A_lambda -> 0 gives

L = S/K, with Hilbert function (1,5,15,20,10,2) and length 53.

In particular S/K is not A_lambda, whose length is 11. The pairing and degree-zero generation show soc(H)=H_5: a nonzero h in H_i for i<5 pairs nontrivially with some element of H_(5-i), which is a sum of positive-degree polynomial multiples of W. Such an h cannot be killed by m. Since L_d=H_d for d>=3, soc(L)=L intersect soc(H)=H_5. Thus S/K is level of socle degree 5 and type 2.

The scalar evaluation map R -> H, r -> rw, has kernel K/I and image L. Consequently K/I has Hilbert function (0,0,0,5,5,1), length 11, and square zero in R by degree support.

## 2. Canonical annihilator duality

Dualize scalar evaluation using D_5 and the pairing H=D_5(H). Its dual map H -> D_5(R)=Sym^2_S(H) is exactly h -> wh, since

Phi(wh)(r)=b(rw,h).

Its cokernel is Sym^2_S(H)/(wH). The symmetric algebra of a quotient gives a canonical identification of this cokernel with Sym^2_S(H/Sw). Since H/Sw is cyclic in degree zero, choosing its generator identifies Sym^2_S(H/Sw) with A_lambda. Exact duality therefore yields

D_5(K/I) = A_lambda, and K/I = D_5(A_lambda),

where the displayed identifications with S/J_lambda depend on that generator choice. In particular the annihilator is independent of the choice, giving the ideal-colon identity

(I:K)=J_lambda.

Indeed Ann_S(K/I)=(I:K), and a finite-dimensional module and its vector-space dual have the same annihilator.

There is also an elementary comparison with orthogonality. Put L^perp={h in H : b(h,L)=0}. Exact pairing duality gives L^perp=D_5(A_lambda). Choose v completing w to a basis of W. The map K/I -> L^perp, f mod I -> fv, is well-defined and injective: if both fw and fv vanish, f annihilates H. Its image is orthogonal to L because b(fv,gw)=b(v,fgw)=0. Its domain and codomain have the already established Hilbert function (0,0,0,5,5,1), so it is an isomorphism. This is a map-based proof, not a module identification inferred from Hilbert functions alone.

For independent w,w' in W one also has Ann_S(w) intersect Ann_S(w')=I, simply because w,w' generate H. No double-annihilator identity is asserted: (I:J_lambda) is not K. For example R_5 is always annihilated by J_lambda, whereas (K/I)_5 has dimension 1 and R_5 has dimension 3.

## 3. Coisotropic reduction gives a compressed Gorenstein algebra

The module L^perp is supported in degrees 3,4,5, with dimensions 5,5,1. But L contains all of H in those degrees. Therefore L^perp is contained in L: every nonzero degree-zero cyclic submodule L is coisotropic.

The radical of b restricted to L is L intersect L^perp=L^perp. Hence the induced pairing on

G_w = L/L^perp

is symmetric, S-balanced and perfect in total degree 5. This module is cyclic, generated by the image of w in degree zero, so it is a quotient algebra of S. Its Hilbert function is

(1,5,15,15,5,1), of length 42.

A cyclic finite graded algebra with such a perfect associative pairing has one-dimensional socle in degree 5. Explicitly, a nonzero element in a smaller degree cannot be in the socle, since perfectness pairs it nontrivially with a positive-degree polynomial multiple of the degree-zero generator. Thus G_w is Artinian Gorenstein. Its Hilbert function is min(dim S_d,dim S_(5-d)), so it is compressed.

Define the ideal T_w={f in S : fw belongs to L^perp}. Then G_w=S/T_w, and

0 -> D_5(A_lambda) -> S/K -> S/T_w -> 0.

Moreover

T_w = Ann_S(w^2 in Sym^2_S H).

To check the equality, a homogeneous f kills w^2 if and only if Phi(fw^2)(q)=b(qfw,w)=b(fw,qw)=0 for every complementary-degree q. Since every element of L is a polynomial multiple of w, this is equivalent to fw being orthogonal to L. Degrees above 5 vanish on both sides.

Equivalently, the quintic functional F_w on S_5 defined by F_w(q)=b(qw,w) is nonzero and has apolar quotient S/Ann(F_w)=G_w, with the preceding Hilbert function. This uses algebraic dual functionals and does not choose or evaluate any actual quintic coefficients.

## 4. A two-layer ideal filtration inside the original scalar algebra

The construction gives I subset K subset T_w and two exact identifications

K/I = D_5(A_lambda),
T_w/K = D_5(A_lambda),

with the same caveat about generator choices. The second follows from multiplication f -> fw identifying T_w/K with L^perp. Thus T_w/I has Hilbert function (0,0,0,10,10,2) and length 22; R/(T_w/I)=G_w has length 42. In particular T_w/I also squares to zero by its degree support. This does not assert that the two-layer extension splits as an S-module.

The pure-square elements w^2 of Sym^2(W)=N_0 therefore all define compressed quintic Gorenstein quotients of the original R. This is a uniform family of quotients of R, not just a construction on an unrelated auxiliary module. The two length-11 layers retain the column quotient as a dual module, while the intermediate length-53 quotient retains the original cyclic action of H.

## Scope

This is a structural derivation conditional on the pinned pairing, scalar Hilbert function and uniform column-quotient results. It is authored mathematical work, not a proof-assistant check. No actual HM matrix, selected source-instance value, numerical rank, coefficient search, or large computation is used. The original fixed-pair residual target K_6/(uK_4+vK_3), higher-order lifting, and algebraicity are not decided by this result; its K is the cyclic annihilator ideal defined above, not that residual module notation. The new contribution is the uniform annihilator-colon identity, the coisotropic reduction to compressed Gorenstein quotients, and the two-layer dual-column filtration inside R.
