# Reproduction and scope

Run python verify.py and python -O verify.py.

The verifier uses nine fixed abstract character values in Q(√5), checks four tensor identities and all displayed character/dimension differences, and checks the fixed-line degree/sign calculation and primary-support bookkeeping. It evaluates no actual HM map or selected source instance. With audit-inputs present, it authenticates all five exact UTF-8 originals against their Git blob hashes.

Expected dimensions: first-arrow source 123; middle 46; canonical reachable image 43; first-arrow relations 80; invariant curry kernel 24; forced common cancellation lower bound 56; invariant curry image 99.

The exact ideal Koszul resolution, cohomology chase, imported structural twist-one vanishing and actual fixed-line splitting remain mathematical proof inputs, not facts certified by character arithmetic. The canonical common image is C_inv(ker a); its abstract forced subrepresentation need not be canonically split, and the bound need not be sharp.

The 43-dimensional result concerns the actual first-arrow image, not the full curried image. The 56-dimensional bound concerns a subspace of Hom(V,N₄), not the 37-dimensional N₄, one chosen quadratic, or an evaluated actual matrix rank. No source exclusion or full-window realization follows.
