# Reproduce the bounded checks

Run python verify.py and python -O verify.py from this directory.
Both outputs must equal RESULT.json byte for byte. The checker uses
the Python standard library only and has no network or large-computation
step. All test failures raise explicitly, so optimization cannot remove
the checks.

The four complete source copies in inputs/ were independently fetched
from the original repository paths at the immutable commits listed in
INPUTS.json. The checker verifies each Git blob hash, SHA256 and length.
To refresh authentication, fetch those exact URLs and compare the raw
UTF-8 bytes, not a rendered Markdown page or a patch excerpt.

Representation calculations are over the fixed field Q(sqrt(5)) on
the nine abstract conjugacy classes of SL2(F5). The largest new primary
symmetric-power degree is4. The small monomial check enumerates only
the fixed quotient with three V variables and two W variables through
degree3, supporting the written all-degrees pigeonhole argument.

These checks do not evaluate a monad differential, source instance,
HM coefficient, point, parameter, jet, matrix, numerical rank or scan.
They do not certify geometric input theorems merely by hashing them.
The actual module injection, physical parity, nonzero mixed multiplication
and complete-annihilator argument are carried by PROOF.md and its
independent whole-proof review.
