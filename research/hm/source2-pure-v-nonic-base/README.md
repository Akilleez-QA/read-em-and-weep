# Pure-V nonic base geometry

This packet studies every nonzero member of the two-dimensional quotient-third gate of PR1025. It proves absence of a common divisor, and identifies two intrinsic exceptional jet lines controlling the prescribed order-five and order-three base loci. It does not determine the actual gate, exact exceptional ideals, or additional finite basepoints.

Run python verify.py or python -O verify.py. Both outputs should equal RESULT.json. Inputs are unchanged immutable public proofs authenticated by INPUTS.json.

The no-common-divisor result and the joint-jet separation are new conclusions for this nonic component system. PR1000's length34 scheme, PR1005's cubic base scheme, and PR1025's gate are inputs. The supporting discriminant-divisor exclusion is not claimed as a separate advance or as the stronger square-restriction theorem.
