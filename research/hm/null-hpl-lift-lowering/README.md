# Portable conditional HPL audit

Run with Python 3.9 or newer from any directory:

    python check.py
    python -O check.py

Use the path to check.py if running outside this directory. All inputs resolve relative to that file. No network, packages, repository checkout, production module imports, or physical computations are needed.

PROOF.md states the conditional theorem. REVIEW.md records the independent audit and its limits. inputs/ contains inert source/proof excerpts with .txt extensions; they are parsed or read only. pins.json binds their exact bytes, original full-file hashes, and extraction descriptions. These original hashes record local authenticated provenance, not a claim that this bundle contains the complete upstream files or independently establishes their external publication.

The original audited files were preserved. This bundle is prepared locally for public use; it has not been published. Mathematical face counts and supports describe abstract formal combinatorics, not a physical execution or resource estimate.
