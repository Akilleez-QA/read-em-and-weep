# Equality-case determinant obstruction

A new universal local theorem strengthens the equality case of the isolated self-dual rank bound: when beta1(P)=r+2 mu(P), the relation representation has determinant equal to that of M*. A double universal-extension construction supplies a free monad and proves the character identity without assuming a symmetry type for the Tor map.

Thus epsilon=+1 cannot be realized by ANY determinant-trivial isolated rank-two reflexive module with the stated action. The separate epsilon=-1 symplectic construction gives existence, completing the sign choice in this family.
