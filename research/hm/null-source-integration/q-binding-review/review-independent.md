## Minor API defect

`ActualQBinding(repo=...)` checks the supplied repository once, but immediately calls `authenticate()` without forwarding it. Later `describe()` constructs actual catalogs using the default repository again. A supplied source repository therefore does not replace the default source lookup. A transport-spy control observed two calls at the explicit directory followed by two at the default directory. Either propagate repo throughout authentication and descriptor construction or remove/document the parameter as an additional check. This is a portability defect, not a defect in the quotient identity.
