# Independent nine-class verification

This directory contains a separate calculation and evidence for the conditional maximal-profile(1,1) closure. The mathematical review is `../REVIEW-INDEPENDENT.md`.

## Files

- `recompute.py`: standard-library-only exact calculation. It locates the packet relative to its own path, so it may be invoked from any working directory.
- `CERTIFICATES.json`: all 159 original ordered row certificates, all 2,226 endpoint height values, complete characters, residual source and shape checks, and the nine-class tables.
- `SUMMARY.json`: final PASS, 8,670 checks, exact partition, hashes and full comparison with `../RESULT.json`.
- Normal and optimized replay output is generated by the commands below; duplicate run-output files are not part of the publication packet.
- `REMOTE-AUTHENTICATION.json`: separate fresh read-only GitHub-fetch evidence for all 14 full pinned inputs, including complete content, returned blob ID and canonical URL comparisons.

The calculation does not import or execute `../characters.py`, `../verify.py`, or `../inputs/original-verifier.py`. It reads the physical class tables from `../inputs/character-reference.py` with a restricted AST evaluator and uses an independent closed binomial formula for symmetric characters. It does not run the historical enumeration and does not consume `compatible_E_types` for any decision.

## Replay

Python 3.10 or later is sufficient. No package installation or network access is needed for the arithmetic replay. Keep `INPUTS.json`, `PROOF.md`, `RESULT.json`, and the `inputs/` directory in the packet root. No duplicate `RESULT.optimized.json` is required.

From the packet root:

```sh
python3 independent/recompute.py
python3 -O independent/recompute.py
```

For an explicit equality check of both outputs:

```sh
scratch=$(mktemp -d)
python3 independent/recompute.py > "$scratch/normal.txt"
cp independent/CERTIFICATES.json "$scratch/certificates.json"
cp independent/SUMMARY.json "$scratch/summary.json"
python3 -O independent/recompute.py > "$scratch/optimized.txt"
cmp "$scratch/normal.txt" "$scratch/optimized.txt"
cmp "$scratch/certificates.json" independent/CERTIFICATES.json
cmp "$scratch/summary.json" independent/SUMMARY.json
rm -r "$scratch"
```

The script generates independent certificates before opening the production result. A mismatch raises `RuntimeError`, including under `-O`. Normal and optimized replays were both run successfully and their output bytes compared.

The offline replay authenticates retained input bytes against the manifest. The separate remote-authentication artifact records the reviewer's fresh complete reads using GitHub `fetch_file` with `repository_full_name=Akilleez-QA/read-em-and-weep`, the exact manifest path, and its exact full commit ref. It is not a claim that an offline replay contacts GitHub. To repeat that external origin check, re-fetch those 14 immutable files, compare complete UTF-8 bytes, and compare the returned blob SHA and canonical URL with the manifest.

## Limits

Only the original fixed 159 records are processed. All representation arithmetic is universal and exact; symmetric degrees through31 suffice. No actual-instance data, chosen points, coefficients, jets, tensors, matrices, instance ranks, scans, historical enumeration, public writes, or large computation are involved.

PASS means conditional exclusion of maximal rank-three profile(1,1). It does not establish the separate global profile-exhaustiveness dependency or a global rank-three/rank-four theorem.
