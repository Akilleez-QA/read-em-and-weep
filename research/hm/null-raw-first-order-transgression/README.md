Run with Python 3 and its standard library only:

    python check.py

The script resolves all inputs relative to itself, so these commands work from any current directory. It manipulates invented free words and scalar symbols, checks small integer frame exponents, hashes inert text, and parses one source function as an AST. It never imports or executes production source, and never constructs actual model matrices, owners, coefficients, or jets. Files ending .py.txt are inert evidence, not runnable dependencies.

The checker uses explicit exceptions rather than Python assert statements. Nine negative controls remain active under -O. Stored normal and optimized outputs are identical. SHA256SUMS binds the delivered files, but hashes are neither signatures nor attestations of historical execution.
