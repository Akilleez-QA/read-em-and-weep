# Finite base support of the pure-V nonic gate

This packet uses the no-divisor and conic-base classifications to bound remaining plane basepoints. The new inputs to the argument are the fifteen involution-fixed-line incidences, their degree-nine restriction bounds, and local curvilinear algebra.

The conclusions are necessary support/multiplicity restrictions only. They do not construct every listed case, determine the actual gate coefficient, identify distinguished parameter lines, or compute exact local schemes on the jet lines. Simple conic intersection is explicitly distinguished from ambient reducedness.

Run python verify.py and python -O verify.py. Both should reproduce RESULT.json. Immutable source proofs and their hashes are recorded in INPUTS.json.
