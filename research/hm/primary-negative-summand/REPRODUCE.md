# Reproduction

Run python verify.py and python -O verify.py. Outputs must be byte-identical and agree with RESULT.json. Python standard-library exact arithmetic suffices.

The checker authenticates the two complete immutable source originals, verifies fixed nine-class representation products and quotient characters, rank/degree/twist bookkeeping, elementary P1 cohomology controls, and the two-dimensional equivariant Hom multiplicity. These are universal representation and bundle-arithmetic checks, never evaluations of selected actual HM/source coefficients or instances.

Saturation requires the actual two coefficient injections and surjective quotient arrow. Splitting requires the proven quotient vanishing and Serre duality. Neither is established merely by running this checker; the written proof and independent whole-proof review provide the mathematical audit. No distinguished complement, horizontal splitting, or full graded-module splitting is asserted.
