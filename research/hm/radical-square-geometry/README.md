# Radical-square image geometry

Exact universal full-coefficient proof of the saturated rank-three radical-square image in necessary types I and II, with quotient sequences. See PROOF.md for hypotheses and limits; RESULT.json retains full matrices and minors. Reproduce with `python verify.py` and `python -O verify.py` using SymPy. INPUTS.json authenticates original public dependencies. This packet does not eliminate a catalogue case or solve the original problem.
