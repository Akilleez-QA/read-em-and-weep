# Original-pair pushforward and Ext-one vanishing

## Result

For f:(P¹)⁴→P⁴ and the original pair coefficient L=O(−2,−2,0,0), the formal incidence calculation gives

f_*L ≅ Ω²_P⁴ ⊕ 9O(−2) ⊕ 9O(−3).

This is an ordinary vector-bundle decomposition in characteristic not two. With the accepted P⁴ cohomology inputs and the characteristic-zero HM bundle identification it proves original-pair Ext¹=0 without the old 450/100/90 staircase ranks. The Euler/duality argument also recovers degree-two dimension 514 conditional on the stated full tables. Multiplicity representations must be restored for any finer equivariant claim.
