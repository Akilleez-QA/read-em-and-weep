# TP01 total request semantics and unconditional execution gate

This is a total normalization and descriptor provider over valid finite owner tuples. It supplies no actual coefficient implementation or release. The actual coefficient, alternating-coefficient, factor-stream and owner-iteration entry points raise PhysicalAdmissionMissing immediately, independently of their arguments or mode attribute. They do not invoke normalization, support tests or structural-zero logic. This distinction is essential: proving a coefficient mathematically zero does not release actual arithmetic through a gated interface.

## 1. Common and source-specific alternation

A common vertex key is(carrier,legal mask,standard tag). Occurrence and seed fields retain provenance and clearing ownership; they do not make repeated opens geometrically distinct. The fixed common order is auxiliary5 first, then primary0..4, numeric legal mask and original standard tag. Every finite tuple has a stable sorting permutation. Its inversion parity supplies exactly one alternating-extension sign. A repeated common key gives a degenerate simplex and the zero plan for every cochain.

The special input F is the pullback of the source-cover two-cochain, so three source slots are required. Its source-cover key is(carrier,legal mask). Repeated physical keys give a zero F plan even when standard tags differ. This is the stronger F-specific zero theorem consumed from null's combined-pole proof and PB/FD. T and Rsharp here are general common cochains: they receive only the common-repetition zero rule. Distinct common vertices with equal physical labels are retained for T/Rsharp. No physical-source zero predicate is propagated through a solver or lift by assumption.

RequestPlan is frozen, and it holds tuples of the existing frozen FullOwner instances, including immutable nested occurrence labels. Sorting does not reassign tags, masks, occurrences or owner slots in the original request. The result retains the original tuple, permutation, sorted tuple, sorting sign, effective sign and zero reason. It explicitly reports occurrence aliasing. Aliasing is not silently repaired by inventing new occurrences; it prevents a joined PB/FD definition description. It does not turn a nondegenerate common simplex into an alternating zero. Coherent seed provenance is required. For T/Rsharp the plan covers every valid finite tuple, including empty and singleton tuples; it does not assert that every such degree is an application of a particular solver formula. F requests have exactly three slots.

## 2. Exact domain without actual enumeration

Full96Descriptor fixes seed, immutable occurrence and standard tag. The complete index domain is0..95, with carrier=k//16 and legal mask=k%16. Division with remainder is a bijection to{0,..,5}x{0,..,15}; its inverse is16*carrier+mask. A pure label_plan(k) exposes one five-field metadata tuple and validates k as an exact integer. The descriptor never deletes zero-weight finite-mask labels or unavailable carriers. It records low-bit legal and high-bit standard encodings separately.

The object cannot be iterated, and its owners method always refuses. The controls query only boundary index examples; they do not traverse the96 actual labels. A product of such descriptors describes a complete source index domain without materializing its Cartesian product, claiming occupied support or providing coefficient values. Descriptor completeness is not a permission to iterate actual fibers.

ToyProvider instead receives explicit small artificial values and owner lists. Each tag has at most4 supplied owners, at most4 tags, with no duplicate common labels per tag. It never derives labels from Full96Descriptor and never falls back to an actual provider. Undefined artificial coefficients are errors, not inferred zeros. Its exact supplied coefficients use the same pure normalization plan: F physical repetition vanishes, common repetition vanishes for all, and nonzero table requests receive the single parity sign. Only the explicit toy owner lists are iterable.

## 4. Resource and mathematical scope

An eventual complete coefficient provider and total-lift program require their own reviewed source/domain composition and a shared prospective schedule before any actual arithmetic.

## Post-review frame-planning correction

Permutation parity alone normalizes scalar F/T values in their fixed common finite pair frame. A raw Rsharp End-valued cochain is instead expressed in the row-End frame at its original first owner. After sorting, its canonical matrix is based at the canonical first owner. Let G=g(original_first,canonical_first), with that exact ordered edge request, which may be reverse ordered. Its original-frame value is parity times G^-1 X_canonical G. The left inverse and right transition are ordered; the edge must not silently be sorted to fetch a forward g. No physical transition or matrix value is evaluated by this plan.

The separate pure frame_plan helper keeps this value-frame routing apart from the already reviewed tuple/permutation semantics, avoiding a change to RequestPlan's frozen constructor fields. RequestPlan.describe includes the route. Frame identity is asserted precisely when original and canonical first common keys agree, even if occurrence provenance differs; both full owners remain recorded without merging their clearings. Empty tuples have no base owner. Zero plans require no transport evaluation, and actual entry points still refuse before any such path. Distinct common tags with equal physical source labels remain nonzero Rsharp plans; a separate transition identity, if later established, cannot replace the cochain's repetition rule.

ToyProvider is explicitly scalar_fixture_only. An artificial scalar fixture named Rsharp does not claim to evaluate End matrices. A separate rational noncommuting control uses G=[[1,1],[0,1]] and X=diag(1,-1), giving G^-1 X G=[[1,2],[0,-1]], which detects the error of using parity alone. The new control also checks original/canonical first-owner routing, ordered reverse-edge metadata, unchanged-first identity, empty/zero cases, fixed-frame scalar F/T and physical-repeat Rsharp survival. Nine producer tests pass normal/-O. Historical independent reviewer artifacts are unchanged.
