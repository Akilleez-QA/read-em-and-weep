# TP01 total gated source/common request provider

`provider.request_plan(cochain,owners,pair)` gives immutable pure normalization metadata for F, T or Rsharp. Repeated common keys are alternating-zero plans for every cochain. Distinct common keys with repeated physical source labels are zero only for F. Full five-field owners and one sorting sign remain explicit. F requires three slots; T/Rsharp planning accepts arbitrary finite tuple degrees without claiming a solver implementation in each degree.

`ActualProvider(repo=None).describe(...)` joins canonical PB/QB/FD source definitions for eligible F triples and supplies normalization-only descriptions otherwise. Repository paths are constrained before authentication. Actual coefficient/factor/owner methods always refuse before zero/support paths, even if mode is changed. No proof dictionaries or verified flags are accepted. T/Rsharp coefficient realization remains with the separate full-source/lift lane.

`Full96Descriptor(seed,occurrence,tag)` describes the complete lazy96-label domain. `label_plan(k)` is a pure per-index metadata map. Actual iteration and owner construction refuse. `ToyProvider` iterates only explicit tiny artificial owner lists and reads only explicit exact artificial coefficients. Missing entries are errors.
