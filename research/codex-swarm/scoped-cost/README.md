# CO02 scoped source cost producer

Actual-source dependency adapter for the reviewed153-node finite F12 DAG, eight seed12/30 E34 branches/four complete N edges, and all121 actual map/exponent demands of the4270-node scalar-family compiler. The package exports deterministic source syntax and integer bounds, with pending complete-B and quotient PROGRAM boundaries intact. It evaluates no physical coefficients and opens no gate.

From repository root:

```sh
python -B research/codex-swarm/scoped-cost/adapter.py
python -B -m unittest discover -s research/codex-swarm/scoped-cost -p test_producer.py
python -B -O -m unittest discover -s research/codex-swarm/scoped-cost -p test_producer.py
```

`adapter-grammar.json` contains the exact finite source and family templates, immutable fixed v5 bindings, eight scoped current DAGs, four padded N/whole-quotient shells, eight finite indexed P call sites, and121 actual coefficient-root entries. `cost-report.json` contains graph traversal/sharing counts, per-node degree/shape/dense-operation bounds and477 explicit unresolved cost-program boundaries. `PROOF.md` explains each count and the limits of its use. `source-pins.json` authenticates reviewed and null-support bytes. `producer-ready.json` hashes only producer-owned files; it is a handoff marker, not review or admission.

Adapter grammar conventions:

- Node IDs are zero-based positions; children precede parents. Finite F12 operands use `refs()`'s exact operation-specific positional grammar. Family nodes preserve their original typed `children` and metadata.
- Fixed current nodes carry exact `payload` arguments as `{node: id}` or `{literal: value}`; their final explicit tracefree wrapper has one child. Interning occurs within one branch only.
- A full owner is `[seed, occurrence, carrier, legal_mask, standard_tag]`. Complete request owners, deleted-prefix weights and tail owners are separately retained. Legal bits use low bit i, standard tags high bit3-i.
- Indexed P call sites bind u/v occurrence IDs, inclusive carrier0..5 and mask0..15 domains, fixed tag matching, slot owners, sorted source extension and root152. Their finite no-sharing expansion bound does not claim an executable coefficient oracle.
- Each combined-edge shell explicitly records complete-B and Qhat program boundaries, padded whole N and the denominator/Delta quotient rule. Differentiation follows whole-sum inserted cancellation, whose witness remains pending.
- Each actual demand records its actual map, exponent, source root, weighted uses, staircase and symbolic owner scopes. Symbolic family sharing does not authorize coefficient sharing across full physical scopes.
- `validate(grammar, report)` reconstructs both authenticated artifacts and rejects any source, scope, operation, count or gate alteration. No user-supplied success flag is accepted.

Native producers can cite exact unresolved IDs and supply authenticated executable coefficient programs, domains, heights, oracle costs and storage schedules. Their current working files are not imported or executed here. Future integration must preserve complete inner standard B, all inserted domains, original frames, closure J3 and full outer owners. No F12/F34 comparison proof is attempted.
