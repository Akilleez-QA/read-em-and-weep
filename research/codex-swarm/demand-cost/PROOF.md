# Exact demand join and cost boundary

For each weighted request r with actual map m=(i,b), let w(r,e) be its integer weight at Laurent coordinate e. The requested scalar is sum_e w(r,e)c(m,e). `demand_join` takes the disjoint union of these labelled terms and partitions it by (m,e). Each group retains every (request ID,weight); no weights are discarded or combined across different requests. Re-expanding the group uses reconstructs the original 32 requests exactly, as checked by the reconstruction test. A coefficient with weight 2 is one coefficient demand and one weighted use, not two independent source evaluations.

The pinned requests have 127 weighted term occurrences and 121 distinct (map,coordinate) pairs, giving six repeated coefficient uses. There are 20 actual maps and 32 coordinates after forgetting the map. Forgetting the map is for reporting only; it would incorrectly merge different scalar coefficients. The sum of absolute weights is 149. None of these counts is a physical operation count or a statement about resource spending.

The optional `co01-demand-grammar-v1` describes a topologically ordered coefficient-demand DAG. Its exact scope key is (actual map, Laurent coordinate, ordered list of full owners, source branch ID, frame). A full owner is (seed, occurrence, carrier, legal mask, standard tag). The traversal accepts references only within the identical scope, never because equations or AST text happen to agree. Reuse is explicit by node ID. The producer does not invent common subexpressions. Input edges with multiplicity are retained.

For a leaf define t(v)=1, and otherwise t(v)=1+sum_(u in inputs(v)) t(u), counting repeated edges repeatedly. Acyclic topological order proves this computes the exact number of visits in the fully unfolded formal expression tree. For the multiset of roots, T=sum t(root). Let U be the number of nodes reachable from those roots. Memoizing each explicit scoped ID once avoids exactly T-U formal node visits. DAG edge references sum the input lengths over reachable nodes. These are syntax traversal counts under the supplied grammar; multiplication, derivative, transport and leaf nodes do not specify polynomial representation, coefficient sizes or physical arithmetic. Thus they cannot upper bound physical work. The toy `(x+x)*(x+x)` has T=7, U=3, four avoided visits and four DAG edges. No source values enter this control.
