# Whole-standard extension and the existing primitive theorem

This is a coefficient-free implication and an exact source-binding checklist. It neither authenticates an oracle by its name/hash nor supplies a physical coefficient. The PH01 physical homogeneous theorem is a premise subject to its independent review; this package does not certify that review.

## 1. The whole-standard extension theorem

Fix pair p=(0,1) or (2,3), and n_i=-2 in p, zero otherwise. Fix a standard target tuple s=(e0,e1,e2). Let u_j be a complete owner over e_j, retaining seed, occurrence, carrier, legal mask, and standard tag. Write

    C_u=H_u^14 product_(i in p) ell_ui,
    c_ui=14 d_u + 1_(i in p) deg(ell_ui),
    D_i=sum_j c_(u_j)i+n_i.

Here d_u=5 for primary carriers and 4 for auxiliary5; legal degree is 1 for mask bit0 and 3 for bit1. These degrees belong to the actual homogeneous divisor sections, including the auxiliary's hidden v0 factor. They cannot be inferred from its affine denominator degree alone.

Assume the following independently authenticated identities for the same fixed source order and physical frames:

1. The complete actual source satisfies `P_u=(product_j C_u_j) F_u`, with P_u a global homogeneous section of multidegree D. P is the whole `b-tr(C)/2` source, not separate unregularized summands. The source-first alternating extension is fixed once.
2. The fixed partition quotient on U_e is an actual regular section `q_u` of O(-c_u), with `rho_u=C_u q_u`. In the global finite frame its Laurent expression is Qhat_u, including exactly the divisor frame conversion prescribed by null's combined-pole proof section 2.

Then each whole summand

    P_u product_j q_u_j

extends to U_e0 intersect U_e1 intersect U_e2 as a regular section of O(n). Proof: restrict each global P and each q_u_j to this intersection and multiply their line-bundle sections. Its degree is D-sum c=n. On the smaller source common overlap it agrees with `(product rho) F` by the assumed identities, so this constructs its extension. A source-sorting sign is a constant and changes none of the conclusions. Sum over the fixed finite fibers to obtain the regular Pi F. Distinct equal-valued factors retain separate owners throughout the argument. The zero predicate for repeated physical source labels applies only to this F pullback.

The exponent version explains why this is whole-standard regularity, rather than regularity on an arbitrarily small common localization. For any coordinate i:

- If every e_j is finite, P has exponent >=0 and all three Qhat factors have exponent >=0.
- If every e_j is infinity, P's finite exponent is <=D_i, while each Qhat exponent is <=-c_(u_j)i. The sum is therefore <=D_i-sum c=n_i.
- If the tags are mixed, that coordinate is inverted on the standard intersection, so no one-sided Laurent inequality is needed.

The exact owner-dependent D is essential. The coarser uniform217/210 upper bound alone does not prove the all-infinity inequality for owners with a smaller D. A regression control constructs this false inference and rejects it.

K's rectangle cone uses only endpoint bits, S's paths have the same intersection as their tensor cell, and h's output inequalities are explicit. Consequently the complete standard B=R(K Pi+A h S Pi)F is a regular standard cochain once these Pi premises hold. There is no additional need to expand a physical source polynomial merely to recheck that regularity theorem. There IS a need to bind the emitted P and Qhat coefficient programs to these exact identities and domains. Those source-faithful oracle identities remain unaccepted by this package.

## 3. Primitive/harmonic zero: existing proof, remaining binding

The generic homotopy has a remainder:

    delta T+T delta=1-R A I P S Pi,
    T=H_rho+R(K Pi+A h S Pi).

The pair character has H2 dimension1. Closedness of F alone does not erase this remainder. STD's artificial harmonic countercontrol correctly demonstrates that failure.

The source-specific vanishing theorem already exists at10810ee, `hm-transition-only-first-lift-alternative.md` section4, blob c8bd02bc22d0da5bdcba6bb50d9c82548b92f990. It imports the explicit old scalar cochain s_old and proves

    delta s_old=F,
    P S Pi s*F=P delta(S Pi s*s_old)=0.

This uses the same pair component, physical determinant-one row transitions, gerbe `b=(15/4)q_a cup q_b`, and representative correction `-15 q_a,ij q_b,ij/8`. Section2 checks s_old's owned carrier14/legal1 domain as well as F's. The same fixed projection/domain and chain-map identities then apply to its differential. Section5 derives `delta T F=F`. This is an algebraic source proof; recomputing its one harmonic scalar is unnecessary.

Its underlying authenticated source is at08b73637d4136f91606aad332c46cafd064417f8, `current-scalar-residual-attribution/first-order-source.md`, blob5f4e56252cd9a8a6eb218aceb911c95a1c330ebc. Sections2–3 derive the scalar from the unsymmetrized transgression, the coefficient-30 square, the exact gerbe representative correction, and row/column trace sign. Section4 binds it to the actual generator conventions. In particular it does not infer exactness from rank two or from traceless first currents alone.

The first-order cochain identity is applied to the intended fresh order by restricting the SAME physical transition/connection construction to increasing tuples and extending alternatingly. An emitted fresh source oracle must be identified with that same `b-tr(C)/2` formula in the same frame, with both terms and all endpoint derivatives retained. A historical nonlinear residual evaluated in another order is not automatically that cochain. Source-order and gerbe/frame equality must be proved at the oracle interface; a reference to a historical value or the statement 'harmonic zero' is insufficient. This is a source-binding task, not a request for new source arithmetic.

## 4. Registry handoff and acceptance scope

`witnesses.py` computes owner-dependent degrees, exposes a strict JSON-compatible proposal validator, and multiplies only capped artificial polynomials to control the extension implication. `witness-schema.json` and `witness-template.json` are machine-readable handoff formats. Candidate proof hashes may be recorded, but no status string can become 'verified'. `validate_proposal` always returns admission and physical identity flags false. `require_actual_admission` always rejects: this package has no trusted physical proof-admission registry.

The next source-interface owner must bind P to the reviewed complete actual source circuit, Qhat to the exact fixed N14 quotient circuit including its owner/chart framing, and the primitive application to the precise first-order equation and its admissible s_old domain. The deliverable is a reviewed identity/domain composition artifact, not a coefficient table. An outer full-lift witness remains a larger obligation: the common54/29/5251 domain must cover whole Rsharp/J0..J3 and every prism/restriction. The inner F/B extension theorem here does not itself certify that outer domain, full closure, detector values, or an arithmetic schedule.
