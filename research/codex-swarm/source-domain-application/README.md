# FD01: full fiber descriptor and fresh source domain

`domain.py` represents every standard fiber by the complete symbolic index product carrier0..5 × legal-mask0..15. It never enumerates its96 actual owners. A separate explicitly tiny toy provider supports artificial controls.

The coefficient-free bridge computes exact owned C degrees, P homogeneous degree D=sum c+pair twist, and quotient frame/reversal bounds. It applies the accepted SW whole-standard extension theorem to the fixed canonical P/Q definitions; no arbitrary catalog, callback or claimed proof status is accepted. `ActualDomainApplication.describe` calls the fixed P/Q producer descriptions on a supplied triple only, checking degrees/frame shifts and retaining source parity/full owners. This metadata adapter is not a complete fiber provider or an execution capability.

`PROOF.md` also proves the fresh scalar primitive identity from the pinned unsymmetrized transgression, square coefficient-30, row/column trace sign and exact gerbe correction. The raw identity holds on any new increasing tuples and is then alternated. The carrier14/legal1 primitive domain is formula-local and unchanged by the new order. Thus harmonic zero follows without recomputing a scalar. Historical nonlinear cochain/order/value comparison remains open.
