# Preserved polar-layer application audit

The polar-layer invariant in POLAR-LAYER-APPLICATION.md is correct, with the displayed Čech convention. If δa=ν*s for a normalized zero-cochain, then its quotient image is a global section of Q_L, and its class modulo the image of H⁰(T,G) maps to [s] under the connecting homomorphism. Changing the normalized primitive changes that quotient section by the indicated image; changing the cocycle representative does not change the class. It vanishes exactly when a can be corrected by a global normalized section to descend. Together with the vanishing of the normalized H¹ class, this is necessary and sufficient for the original H¹ class to vanish.

The common k=3 argument also has the correct scope: H¹(F_i(3D))=0 removes the closed-meromorphic ambiguity for that highest layer only. It does not imply lower layers vanish, and PROOF.md explicitly preserves that distinction. No further correction was found in the final skim.
