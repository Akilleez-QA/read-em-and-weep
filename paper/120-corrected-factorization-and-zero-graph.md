## Canonical correction on all M3

Let H=ker Q3, J=ker j3, K=H∩J and L_Θ=Θ(H). The marked decomposition (F3)_T=I3⊕L_Θ defines a canonical isomorphism a:I3→L_Θ by a(j3u)=Θu for u∈H. It is well-defined because both restrictions have kernel K.

The exact full-domain identity is

    Θ = a j3 + ℓQ3 on all M3.

The correction is essential: Θ=ℓQ3 alone remains valid only on J. Indeed Θ−aj3 takes values in I3 and kills H, so factors through Q3; surjectivity Q3:J→V5 identifies that factor with the original ℓ. Equivalently the canonical I3 and L_Θ projections of Θ are ℓQ3 and aj3. No right inverse or graded-module extension is selected.

## Separated zero incidence

Fix the genuine terminal separation V5=V0⊕NR5, with V0≅2T. Write ℓ0=ℓ|V0 and τ=ℓ|NR5 as actual maps. In the nonzero-N0 mechanism F5 is the actual graph of a unique g:V0→NR5. Then

    R=0 ⇔ ℓ0+τg=0.

Since ℓ is onto, zero R forces τ≠0, and then

    g=−τ⁻¹ℓ0.

Thus **τ=0 forces R≠0 in the separated mechanism**. For τ≠0 there is only one possible zero graph for this fixed actual row; the theorem does not assert that the actual graph equals it. In residual-large, by contrast, R=0 iff τ=0 because F5=NR5. These statements use the same row and subspaces of the retained object; they do not transport τ values across distinct source instances.

If τ=0, actual residual surjectivity also forces ℓ0 e0 Q3(NR3)=I3. Hence Q3 cannot preserve the residual degree-three-to-five block in that case. This proves an off-diagonal detection, not the rank of the entire off-diagonal block or a general Q-stability claim.

## What the operator identities do not select

A formal multiplicity control verifies that the two-generator square-zero action and corrected identity alone allow a free terminal restriction. It is not an actual source module and omits the full negative arrows and geometry. Accordingly neither τ, the graph incidence nor a remaining mechanism is selected. Zero R is still unexcluded when the unique-graph condition can hold. No positive/full-adjoint rank follows from this result alone.
