## Paths and reproducibility

Relative paths inside the archive retain their original relationships. Run archive-specific commands from their original working directory under the new prefix; for example, Lean work begins in `upstream/openai-math/lean/`, using that directory's own instructions. No dependency update, Lean rebuild or third-party patch execution was performed merely to relocate the tree.

Historical immutable commit links remain valid. Existing research branches and pull requests are not rewritten or bulk-merged by this layout change. Future merges that modify an original upstream path must deliberately target its archived location rather than restoring a second copy at the root.
